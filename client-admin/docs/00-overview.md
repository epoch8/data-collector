# 00 — Обзор client-admin

## 1. Назначение

**client-admin** — веб-интерфейс для сотрудников проекта (операторы, разметчики, QA), который работает с **уже принятыми пакетами** на платформе.

Задачи:

1. **Просмотр** собранных данных (GT): поля формы, фото/видео, метаданные камеры.
2. **Визуализация** результатов обработки: inference, статусы пайплайнов, разметка.
3. **Правка** значений в manifest.
4. **Проектные расширения** (плагины): например, интеграция с АИС «монолит» для коров, доменные подсказки.

## 2. Архитектурный контекст

```
┌─────────────┐     upload      ┌──────────────────────────┐
│  Мобилка    │ ──────────────► │  Платформа (django_server) │
│  (сбор)     │   manifest+blobs │  · PackageSession         │
└─────────────┘                 │  · commit → pipelines[]   │
                                │  · merge → manifest JSON  │
                                └────────────┬─────────────┘
                                             │ read / patch
                                             ▼
                                ┌──────────────────────────┐
                                │  client-admin             │
                                │  · экран пакета, виджеты  │
                                │  · клиентские интеграции  │
                                └──────────────────────────┘
```
