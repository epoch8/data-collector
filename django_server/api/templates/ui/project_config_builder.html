С чего начать

Шаг 1

Поля. Описываете всё, что может понадобиться на экранах: идентификатор, тип, подписи. Это справочник; что реально показать и в каком порядке — решает сценарий.

Шаг 2

Сценарий. Собираете экраны: шаг scroll_form = один скролл-экран и список полей на нём; при необходимости — финальный review. Каждое поле из таблицы должно встретиться ровно в одном шаге.

Шаг 3

Проверка и сохранение. «Проверить» — валидация без записи. Картинки для инструкций — на странице «Файлы» этого проекта.

Сценарий: только scroll_form и review. Объект config.ui (подписи в приложении) правьте во вкладке JSON или в режиме «Только JSON».
