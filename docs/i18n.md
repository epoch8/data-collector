# Documentation languages

## Convention

- **`*.md`** — English (default on GitHub).
- **`*.ru.md`** — Russian (same path, `.ru` before `.md`).
- Every paired document starts with a **language switcher**:
  - English: `> **Language / Язык:** **English** · [Русский](FILENAME.ru.md)`
  - Russian: `> **Language / Язык:** [English](FILENAME.md) · **Русский**`
