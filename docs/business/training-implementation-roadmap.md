# Дорожная карта реализации обучения

## Формат


| Формат                   | Роль в программе                                 | Как делать нескучно                                                                           | Примерный объем                       |
| ------------------------ | ------------------------------------------------ | --------------------------------------------------------------------------------------------- | ------------------------------------- |
| видео                    | Быстрое объяснение перед практикой               | 7-15 минут, один конкретный вопрос, демонстрация экрана или схемы                             | 35-45 видео                           |
| Живой семинар            | Разбор сложных тем и решений                     | Демо, совместный разбор пакета, вопросы и ответы                                              | 10-15 сессии внутри 15 часов созвонов |
| Практикум                | Основная практика на стенде                      | Участник делает руками и видит результат в системе                                            | 5-10 практикума                       |
| Разбор инцидента         | Эксплуатация и диагностика                       | Заранее сломанные кейсы: загрузка, `datapipe`, визуализация, хранилище                        | 8-12 кейсов                           |
| Ролевое задание          | Практика по роли                                 | Full-stack: сквозной сценарий и UI/API; ML: пайплайн, модель, метрики                         | 5-7 заданий на роль                   |
| Ревью кода или пайплайна | Проверка способности самостоятельно вести проект | Реализовать полный сквозной сценарий в новой предметной области, например бонитировке баранов | 3-5 ревью на участника                |

## Материалы по блокам

### Data Collector


| Материал                    | Формат                       | Основной сценарий                                                      |
| --------------------------- | ---------------------------- | ---------------------------------------------------------------------- |
| Обзор Flutter-клиента       | Видео + схема                | Где живут проекты, wizard, Drift, история, синхронизация               |
| Динамический конфиг проекта | Практикум                    | Изменить `collector/config.json`, увидеть новый сценарий в клиенте     |
| Структура пакета            | Видео + практикум            | Разобрать `payload.json`, blobs и метаданные камеры                    |
| Протокол загрузки           | Практикум + разбор инцидента | POST session -> PUT blobs -> PUT manifest -> commit                    |
| Админка Django              | Видео + практикум            | Пакеты, медиа, визуализация                                            |
| Конфиг визуализации         | Практикум                    | `collector/viz.json`, патчи для визуализации keypoints/depth/YOLO/CVAT |
| Роли и доступы              | Практикум                    | Назначить пользователя и проверить видимость проектов                  |


### DataPipe

Так как `datapipe` находится в отдельном проекте, материалы нужно вести отдельным пакетом, но связать их с теми же учебными данными.


| Материал               | Формат                   | Основной сценарий                                                       |
| ---------------------- | ------------------------ | ----------------------------------------------------------------------- |
| Карта `datapipe`       | Видео + схема            | Что является входом, шагом, артефактом и результатом                    |
| Таблицы project DB     | Практикум                | Найти package, annotations, inference, depth, CVAT links                |
| Экспорт/импорт CVAT    | Практикум                | Связать фото пакета с задачей разметки                                  |
| Шаг инференса          | Практикум                | Запустить или перезапустить inference до появления результата в админке |
| Отчет по метрикам      | Практикум + шаблон       | PCK, ошибка измерений, сравнение VLM/model/expert                       |
| Версионирование модели | Видео + разбор инцидента | Смена модели, откат, проверка качества                                  |
| План дообучения        | Задание                  | Отобрать данные, описать критерии запуска дообучения                    |


### Korovas Layer


| Материал                 | Формат                 | Что должно остаться после курса                      |
| ------------------------ | ---------------------- | ---------------------------------------------------- |
| Карта бонитировки        | Видео + шпаргалка      | Что такое 21 точка, 15 параметров, 9 признаков       |
| Правила съемки КРС       | Интерактивный чек-лист | Участник понимает, какие фото пригодны для inference |
| Ошибки съемки и разметки | Галерея кейсов         | Набор хороших/плохих примеров                        |
| Эксперт vs модель        | Семинар + практикум    | Участник умеет объяснить расхождение результата      |
| Коровы                   | Набор пакетов          | Основа для практикумов, инцидентов и аттестации      |


## Задание на стенде


| Проект             | Назначение                                | Данные                                         |
| ------------------ | ----------------------------------------- | ---------------------------------------------- |
| `demo-basic`       | Универсальный сбор без доменной специфики | 5-10 простых пакетов                           |
| `demo-cv`          | CV/visualization без КРС                  | YOLO/depth/keypoints examples                  |
| `korovas-training` | Основной учебный проект заказчика         | 30-50 пакетов с фото, CVAT links, GT/inference |
| `korovas-broken`   | Инциденты                                 | Набор намеренно сломанных пакетов и конфигов   |


### Сценарии


| Сценарий                           | Успешный результат                                            |
| ---------------------------------- | ------------------------------------------------------------- |
| Снять пакет в мобильном приложении | Пакет появился локально и готов к upload                      |
| Загрузить пакет                    | На сервере есть session, blobs, manifest, status `completed`  |
| Проверить хранилище                | Blob открывается из project storage, запись есть в project DB |
| Запустить `datapipe`               | Для package появились inference/depth/CVAT rows               |
| Открыть визуализацию               | В админке видны слои GT/inference/CVAT/depth                  |
| Разобрать сбой upload              | Есть гипотеза, логи, фикс или понятная эскалация              |
| Разобрать сбой `datapipe`          | Понятен упавший шаг, входные данные и план восстановления     |
| Сравнить модель и эксперта         | Есть отчет по метрикам и рекомендации                         |
