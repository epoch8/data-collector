# Руководство пользователя: мобильное приложение

> **Это пример** пользовательского пути на конкретном проекте — сбор данных по КРС
> (проект «Хозяйство» / `korovas`). Он показывает **общий поток** приложения
> Калмыцкого государственного университета:
> вход → выбор проекта → заполнение формы по конфигу → отправка пакета на сервер.
> В вашем проекте поля и шаги будут другими — они задаются конфигом в админке
> (см. [руководство по админ-панели](../admin-panel/README.ru.md)), но логика работы та же.

## **1. Вход в приложение**

Укажите email и пароль, которые выдал администратор университета. На экране входа — знак университета и форма email / пароль.

---

## **2. Выбор проекта**

1. Откройте вкладку **Проект**.
2. Выберите проект хозяйства.

**Важно:** настройка доступа и шаги проектов задаются администратором в административной панели. Подробнее в гайде по админ-панели.

Ожидаемая модель: **отдельный проект на каждое хозяйство**. Проекты могут совпадать по структуре, но различаться по названию.

---

## **3. Заполнение полей проекта**

Заполните поля выбранного проекта в соответствии со сценарием сбора данных.

1. Общие параметры.
2. Инструкция по съёмке.
3. Фото по ракурсам, с последовательной сменой ракурса.
4. Форма проверки результата с возможностью поправить поля.

## **4. Загрузка данных на сервер**

Собранные пакеты сначала сохраняются на телефоне. После сбора их нужно отправить на сервер.

1. Перейдите на вкладку **Сервер**.
2. Нажмите **Загрузить**, чтобы отправить данные на сервер.

---

## **5. Дополнительные возможности**

| **Возможность** | **Описание** |
| --- | --- |
| **История загрузки пакетов** | Просмотр истории и текущего статуса пакета (отправка, доставка, ошибки). |
| **Тема оформления** | Переключение между светлой и тёмной темой. |
| **Язык интерфейса** | Русский и английский. |
| **Справка** | Кнопка справки открывает краткое руководство. |
| **Сессия** | При повторном открытии приложения сессия восстанавливается автоматически. |
| **Предзаполнение полей из локальной истории** | Если по корове уже заполняли данные на этом телефоне, поля подтягиваются из локальной базы. |
| **Проверка качества кадра** | Проверка кадра на размытие и засвет. |

История группирует данные по корове: список животных, пакеты по каждому животному и просмотр содержимого пакета с выгрузкой.
