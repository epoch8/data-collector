# Языки документации

## Соглашение

- **`*.md`** — английский (по умолчанию на GitHub).
- **`*.ru.md`** — русский (тот же путь, `.ru` перед `.md`).
- Каждый парный документ начинается с **переключателя языка**:
  - English: `> **Language / Язык:** **English** · [Русский](FILENAME.ru.md)`
