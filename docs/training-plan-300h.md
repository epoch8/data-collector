# План обучения команды сопровождения (300 ч)

**Состав:** Full-stack + ML Engineer 

**Формат:** **300 ч** предметного специалиста e8 на всю программу. **Ставка:** 3 300 ₽/ч → **990 000 ₽**.

| Колонка | Содержание |
| --- | --- |
| **Подг** | Материалы, стенды, кейсы, формулировки ДЗ, чек-листы |
| **Проверка** | Разбор сданных заданий, комментарии, приёмка ДЗ |
| **Созвоны** | Очные/синхронные сессии, семинары, Q&A |
| **Освоение** | Самостоятельная работа студента (для календаря) |
