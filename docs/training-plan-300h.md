# План обучения команды сопровождения — 300 часов

**Формат:** 300 ч на специалиста (≈ 7,5 недель при 40 ч/нед).

**Треки:** общий фундамент (все) → специализация **Full-stack** или **ML Engineer**.

**Ключевая идея:** вся серверная обработка данных идёт через фреймворк **datapipe** — единая «труба»: загрузка в CVAT, инференс моделей, запись результатов, триггеры на пакетах. И мобилка, и админка, и пайплайны — части одной системы.

---

## Роли

| Состав | Кто |
| --- | --- |
| Минимальный | Full-stack, ML Engineer |
| Полный | + мобильный разработчик, DevOps |

### Full-stack — что должен уметь

Один человек закрывает **весь продуктовый контур**:

- мобильное приложение (сбор, камера, офлайн, загрузка)
- веб-админка (пакеты, конфиги проектов, роли)
- datapipe-пайплайны (запуск, диагностика, доводка до визуализации в админке)
- просмотр ML-результатов (keypoints, depth, детекции) в интерфейсе

### ML Engineer

Модели, метрики, разметка — но **внутри datapipe**, а не отдельными скриптами.
